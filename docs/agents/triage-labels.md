# Triage 标签

这些 skill 用五个固定的 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| skill 里的角色 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以直接交给 agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不予处理 |

当某个 skill 提到一个角色（例如「打上可交给 agent 的 triage 标签」）时，用表里对应的标签字符串。
