# Security Policy

## Supported versions

Only the current `main` branch is supported. Older commits receive no fixes.

## Reporting a vulnerability

Use GitHub private vulnerability reporting on this repository's Security tab ("Report a vulnerability"). Do not open a public issue for security problems.

Include the affected version or commit, the pi or omp version you run, reproduction steps, and the impact you observed.

## Scope

This repository ships a pi extension that loads into the pi or omp coding agent process. It starts no network service. Vulnerabilities in the coding agent itself or in model providers belong to those projects.
